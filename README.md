# 🏎️ Formula 1 Performance Analytics

An end-to-end data analytics portfolio project built using SQL and Python to explore Formula 1 race data and uncover performance insights through data analysis and visualisation.

---

## 📌 Project Purpose

The aim of this project is to demonstrate practical data analytics skills by analysing historical Formula 1 data.

The project is being developed incrementally while following professional software development practices including Git version control, documentation, database design and reproducible analysis.

---

## 🎯 Objectives

This project will investigate questions such as:

- Which drivers consistently outperform their teammates?
- How much does qualifying position influence race results?
- Which drivers gain the most positions during races?
- Which constructors have performed best over time?
- Which circuits favour particular teams or drivers?
- How have driver and constructor performance trends changed over multiple seasons?
